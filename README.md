# Hi, I'm Awais

I build practical tools and resources for people publishing websites, blog posts and images.

## Tools I work on

| Task | Tool | Useful starting point |
|---|---|---|
| Prepare images for a website | [TinyImage](https://tinyimage.io/) | Compression, conversion and resizing; check the current website limits and processing policy before uploading |
| Check backlink-profile strength | [DR Checker](https://dr-checker.com/) | Domain Rating lookup; DR is a third-party metric, not a Google ranking score |
| Convert a phone photo to PNG | [HEIC to PNG](https://heictopng.io/) | A PNG intermediate when your editor does not accept HEIC |
| Convert a phone photo to JPEG | [HEIC to JPEG](https://heictojpeg.io/) | A compatible photographic export when your CMS does not accept HEIC |

**Affiliation:** I am affiliated with these four tools. The resources below include alternatives and practical limitations so readers can choose for their own workflow.

## Guides and runnable examples

- [Web publishing image examples](https://github.com/iamawaisyounas/web-publishing-image-examples): a local Python file-inventory script, tests, a responsive-image markup example and a publishing checklist. The script does not upload files or call a product API.
- [Practical Image Workflows for Web Publishing](https://github.com/iamawaisyounas/practical-image-workflows): format choices, HEIC conversion, image preparation, privacy and reproducible comparisons.
- [Free Tools for Website Publishing and SEO Checks](https://github.com/iamawaisyounas/free-web-publishing-seo-tools): tools organized by publishing task, documented free access, sources and limitations.

## How I evaluate a publishing tool

Keep an untouched original. Compare real output bytes and appearance at the published size. Check free limits, processing location and metadata handling. Treat a successful export, a lab performance score and a search ranking as separate observations.

Suggestions and corrections are welcome through issues on the relevant resource repository. Please include a source and verification date for changing product claims, and reproducible records for measurements.
